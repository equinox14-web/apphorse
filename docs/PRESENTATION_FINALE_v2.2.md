```
╠═══════════════════════════════════════════════════════════════╣
║                                                                 ║
║  📊 Ajustement automatique basé sur vos retours                 ║
║                                                                 ║
║  ⭐⭐ (Too Hard)    → -20% intensité                           ║
║  ⭐⭐⭐⭐ (Too Easy) → +10% difficulté                          ║
║  "Boiterie"        → 🚨 ARRÊT immédiat                         ║
║                                                                 ║
╚═══════════════════════════════════════════════════════════════╝

╔═══════════════════════════════════════════════════════════════╗
║  RULE 3: CONTEXTUAL AWARENESS (Environnement)                  ║
╠═══════════════════════════════════════════════════════════════╣
║                                                                 ║
║  🌡️ Adaptation automatique météo/sol                           ║
║                                                                 ║
║  >30°C (Canicule)  → -30% intensité + hydratation renforcée    ║
║  Sol gelé          → 🚨 AUCUN saut/vitesse                     ║
║  Pluie/Orage       → Indoor prioritaire                         ║
║                                                                 ║
╚═══════════════════════════════════════════════════════════════╝
```

### Ordre de Priorité

```
1️⃣ SAFETY (santé, sol dur, boiterie)
   → OVERRIDE ABSOLU de toutes les autres règles

2️⃣ KNOWLEDGE UPDATES (réglementations)
   → OVERRIDE de la connaissance interne

3️⃣ FEEDBACK LOOP (notes utilisateur)
   → ADAPTATION de la difficulté

4️⃣ ENVIRONMENTAL (météo/sol)
   → ADAPTATION de l'intensité/lieu
```
