║  → Note ≥ 4/5 + "Trop facile": +10% difficulté                  ║

║  → "Boiterie": ARRÊT IMMÉDIAT + Vétérinaire                     ║
║                                                                 ║
║  RULE 3: CONTEXTUAL AWARENESS (Environnement)                   ║
║  ────────────────────────────────────────                       ║
║  → Canicule >30°C: -30% intensité + hydratation renforcée       ║
║  → Sol gelé: AUCUN saut/vitesse - Marche uniquement             ║
║  → Sol boueux: -25% durée, renforcement naturel                 ║
║  → Pluie/Orage: Indoor prioritaire, pas de saut outdoor         ║
║                                                                 ║
║  ORDRE DE PRIORITÉ:                                             ║
║  1. SAFETY → 2. KNOWLEDGE → 3. FEEDBACK → 4. ENVIRONMENT       ║
║                                                                 ║

```

   → Soins tendons OBLIGATOIRES après Breeze/Gaz

4. ⚠️ CSO
   → Pas de gros sauts J-3 avant compétition

5. 🚨 SOL GELÉ/DUR
   → AUCUN saut/vitesse - Marche uniquement

6. 🚨 BOITERIE
   → ARRÊT IMMÉDIAT + Repos + Vétérinaire

7. ⚠️ CANICULE >30°C
   → -30% intensité + hydratation renforcée

```
