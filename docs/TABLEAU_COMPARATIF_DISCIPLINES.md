## Notation Vitesse par Discipline

```
Hack       → Récupération légère
```

### TROT (Réduction Kilométrique)
```

1'20"/km   → Vitesse élevée
1'15"/km   → Course Groupe 1
1'10"/km   → Record exceptionnel

OU VERBAL:
Train      → Tempo soutenu
Demi-vite  → Vitesse modérée
Vite       → Vitesse maximale
```

### ENDURANCE (BPM)
```
120-140 BPM → Aérobie léger
140-160 BPM → Tempo travail
160-180 BPM → Seuil anaérobie
180+ BPM    → Lactique (éviter)
```

## Soins Spécifiques par Discipline

### GALOP (Tous types) - TENDONS CRITIQUES ⚠️
```
APRÈS CHAQUE BREEZE/GAZ:
1. Palpation tendons (chaleur, gonflement)
2. Argile froide 30min
3. Glace sur boulets
4. Repos box 24h minimum
5. Surveillance locomotion

SIGNAUX ALERTE:
🚨 Chaleur excessive
🚨 Gonflement anormal
🚨 Boiterie légère
→ STOP + Vétérinaire immédiat
```

### TROT MONTÉ - DOS CRITIQUE ⚠️
```
APRÈS CÔTES/GAINAGE:
1. Étirements dorsaux
2. Massage chaîne dorsale
3. Box spacieux (roulade)
4. Marche main 10min

SIGNAUX ALERTE:
🚨 Raideur dos
🚨 Difficulté flexion
🚨 Réticence sous selle
→ Ostéo + Vétérinaire
```

### CSO - MEMBRES ⚠️
```
APRÈS GROS SAUTS:
1. Douche froide membres
2. Bandes de repos
3. Palpation tendons/boulets
4. Marche main 15min

SIGNAUX ALERTE:
🚨 Chaleur articulaire
🚨 Gonflement boulet
🚨 Boiterie post-séance
→ Repos + Vétérinaire
```

## Checklist Rapide de Génération

### Avant de générer un planning:

```
🐴 CHEVAL
  ✓ Race adaptée à la discipline
  ✓ Âge > 3 ans (sauf loisir)
  ✓ Poids estimé renseigné
  ✓ Niveau/forme actuelle précisé

🏇 CAVALIER/DRIVER
  ✓ Nom renseigné
  ✓ Niveau adapté (Galop 1-7 ou Pro)

🎯 OBJECTIF
  ✓ Discipline choisie
  ✓ Sous-discipline précisée si GALOP/TROT:
    - GALOP: "PLAT" ou "HAIES" ou "STEEPLE"
    - TROT: "ATTELÉ" ou "MONTÉ"
  ✓ Fréquence adaptée au niveau
  ✓ Focus détaillé (>20 caractères)
  
📅 COMPÉTITION (optionnel)
  ✓ Date cible renseignée
  ✓ Nom événement précisé
  ✓ Délai réaliste (>2 semaines)
```
