## 🎯 Cheat sheet intégration

### Importer les composants
```jsx
import PhotoGallery from '../components/PhotoHistory/PhotoGallery';
import PhotoUpload from '../components/PhotoHistory/PhotoUpload';
import PhotoComparison from '../components/PhotoHistory/PhotoComparison';
import { usePhotoHistory } from '../hooks';
```

### Utiliser dans une page
```jsx
const { user } = useAuth();
const { currentHorse } = useHorse();

<PhotoGallery userId={user.uid} horseId={currentHorse.id} />
<PhotoUpload 
  userId={user.uid} 
  horseId={currentHorse.id}
  horseData={currentHorse}
/>
```

### Rien ne fonctionne ?
1. Vérifier userId + horseId passés ✅
2. Vérifier Firestore rules permet read/write ✅
3. Vérifier cloudPhotoService existe ✅
4. Vérifier console logs (📸 ✅ ❌) ✅
5. Lire PHOTO_GALLERY_INTEGRATION_CHECKLIST.md ✅

## ❓ FAQ rapide

**Q: Faut-il passer du temps sur la config?**  
R: Non, tout fonctionne out-of-the-box si services existent

**Q: Faut-il apprendre Firestore?**  
R: Non, API abstraite dans firestoreService (juste utiliser)

**Q: C'est responsive mobile?**  
R: Oui, 100% responsive (testé 2-4 colonnes)

**Q: Ça marche offline?**  
R: Oui, offline queue auto + localStorage fallback
